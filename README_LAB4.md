# StudyFlow 2.0 — лабораторна робота №4

## Що нового
- Реєстрація та вхід; серверні сесії в підписаних HttpOnly-cookie (7 днів).
- Паролі: PBKDF2-HMAC-SHA256 із випадковою сіллю.
- Приватні предмети, заняття, завдання, календар і статистика кожного акаунта.
- Профіль, редагування імені, завантаження/видалення аватара (JPG/PNG/WebP до 200 КБ).
- Перевірка форм у браузері й на FastAPI, повідомлення про помилки.
- Збереження теми та тижневої цілі в localStorage.
- Головна сторінка Desert Sage, окремі сторінки предметів, завдань, календаря, таймера, аналітики та рекомендацій.
- Експорт статистики у CSV.

## Як запустити на Windows
1. Розпакуйте ZIP. Відкрийте `StudyFlow_Updated/lab3` у VS Code.
2. У терміналі PowerShell виконайте `powershell -ExecutionPolicy Bypass -File .\START_STUDYFLOW.ps1`.
3. Дочекайтеся повідомлення і відкрийте http://127.0.0.1:8000. Swagger: http://127.0.0.1:8000/docs.
4. Зареєструйте акаунт і увійдіть. Зупинка: Ctrl+C.

Збірка frontend на Windows виконується під час запуску, тому не відкривайте стару папку `backend/static` без збірки.
Файл `backend/.env` із попереднього проєкту збережено: створювати його заново не потрібно.
Python `.venv` і Windows `node_modules` також збережено. Якщо npm повідомить про відсутні залежності, виконайте у frontend `npm ci`, а тоді повторіть запуск.

## Як повернути предмети лабораторної №3
Для безпеки старі записи **не прив'язуються автоматично до першого-ліпшого акаунта**. Після реєстрації свого акаунта виконайте в `backend`:

```powershell
.\.venv\Scripts\python.exe claim_legacy.py ваша_пошта@example.com
```

Побачите кількість старих записів; підтвердьте перенесення словом `ТАК`. Скрипт не видаляє їх, а прив'язує до вашого акаунта. Якщо у базі були дані кількох людей, **не запускайте цей скрипт**, поки не визначите, кому вони належать.

## Тестування
У `backend` запустіть `python -m pytest -q`. Під час розробки пройдено 20 тестів із SQLite; перевірки реальної Supabase та збірку Windows-фронтенду потрібно виконати на вашому комп'ютері.

## Безпека
Не публікуйте цей ZIP, тому що в ньому на ваш запит збережено `backend/.env`. Якщо архів уже був оприлюднений, змініть пароль Supabase. Для розгортання через HTTPS потрібно встановити для cookie `secure=True` у `backend/app/routers/extras.py` і використовувати окремий `SESSION_SECRET`. Для навчального локального запуску використовується `secure=False`.
